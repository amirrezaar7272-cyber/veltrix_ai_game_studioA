# Hogwarts Infinity

An independent Persian-first fan-made wizarding-world portal.

## Current prototype
- Responsive RTL landing page
- Academy course catalogue and demo enrollment form
- Four Hogwarts house overview
- Searchable spell index
- Interactive sorting quiz

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Important
This is an unofficial fan project and is not affiliated with or endorsed by Warner Bros., J.K. Rowling, or other rights holders. Names and references to the Wizarding World belong to their respective owners.

The current course registration is a browser-only demonstration. Real accounts, persistent enrollment, live video classrooms, teacher dashboards, attendance, and assessments require a backend and a video-conferencing provider. No real live classes are currently hosted.

## Deployment
The included GitHub Actions workflow publishes the static site to GitHub Pages when changes are pushed to the `hogwarts-infinity` branch. Enable GitHub Pages with **GitHub Actions** as the source in repository Settings if required.
