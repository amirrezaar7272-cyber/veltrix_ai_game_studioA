# VELTRIX Brain

Train the tiny from-scratch character model with Python 3.10+ and NumPy:

`python -m pip install numpy`

`python brain/train.py brain/corpus.txt app/src/main/assets/veltrix_model.json`

The included bilingual corpus is only a smoke-test seed and is far too small for useful language ability. Training has not been run and no trained weights are bundled. This character-level MLP is a learning prototype, not a general-purpose LLM.

## Internet lookup
The app offers a DuckDuckGo Instant Answers lookup mode. It summarizes available abstract/related-topic snippets; this is not full web search and may return no answer for many queries. It needs internet. The summary is assembled from provider text, not generated by the neural model. Search queries are sent to the provider.
